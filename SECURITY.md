# Security policy

Please do not open public issues for suspected credential exposure, malicious plugin behavior, authorization bypasses, or vulnerabilities in the Hub approval/effect boundary.

Report vulnerabilities privately to `security@dshx.io` with affected versions, reproduction steps, impact and the smallest useful evidence. Do not include live secrets or personal data that is not necessary to reproduce the issue.

The Hub verifies plugin declarations, archive contents and npm integrity without running third-party install scripts. Verification is not a security guarantee; reports about a published plugin may also be filed through the Hub community reporting flow.

Immutable approval and moderation evidence is retained after account deletion when it is required for security and auditability.
