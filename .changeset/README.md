# Changesets

Run `pnpm changeset` for publishable package changes. Framework and `create-dshx` are a fixed group; the Hub CLI versions independently. The website is private and deployed manually.

All public packages remain on the `0.1.x` development line until an explicit release-policy decision changes it. Use `patch` changesets for features, fixes, and breaking development changes. CI rejects `minor` and `major` changesets for these packages.
